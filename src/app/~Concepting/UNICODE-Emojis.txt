USAGE TIPS
═══════════════════════════════════════════════════════════════════

1. Copy-paste directly into HTML templates - they're just text!

2. Some symbols may render differently across fonts/platforms
   - Emoji (🎨) are colorful and platform-specific
   - Unicode symbols (☰) are monochrome and more consistent

3. Use emoji variants (add ️ variation selector) for consistent rendering
   Example: 👁 vs 👁️

4. Test across browsers - most modern browsers support all these

5. For web development:
   - Direct use: <button>✓</button>
   - HTML entity: <button>&#x2713;</button>
   - Unicode escape in CSS/JS: "\u2713"

6. Some symbols are wider than others - test in your UI

7. Accessibility: Add aria-label or title for screen readers
   Example: <button aria-label="Close">✕</button>
